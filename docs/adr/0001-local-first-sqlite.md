# Локальное хранение с sync-ready схемой

Данные живут только на телефоне: `expo-sqlite`, без бэкенда. Схема с первого дня содержит UUID PK, `updated_at` и мягкие удаления (`deleted_at`) — чтобы синхронизация (Google Drive / Supabase / Convex, решение о выборе — фаза 2) не потребовала миграций. Альтернатива «сразу облако» отклонена: приложение для одного владельца и одного телефона, офлайн-ввод важнее сетевой надёжности, а локальный ввод не должен ждать сети.
