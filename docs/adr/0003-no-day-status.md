# У дня нет статуса

У дня нет статусов «норма/проблема/не отслеживался»: пустой день означает «не отслеживался», а не «всё ок». Любые выводы о проблемах делаются из структурированных данных и заметок. Это остановит «чинку» в виде бейджей вроде «норма 100%» из макета — иначе приложение показывало бы норму там, где данных просто нет.
