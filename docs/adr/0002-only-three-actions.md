# Строго три действия, всё остальное — заметки

Отслеживаются только поела / пописала / покакала — с преднастроенными характеристиками. Всё остальное (рвота, вода, лекарства, «вне лотка», кровь) — свободные заметки без ограничений количества, с опциональным временем. Это осозненное отклонение от дизайна-макета с шестью категориями: ввод остается простым, а счёт рвоты/воды не нужен — текст читают и человек, и LLM при анализе истории для врача.
