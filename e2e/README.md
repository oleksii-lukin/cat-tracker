# E2E (Maestro)

## Прогон

**Рекомендуемый способ (с гарантированным порядком):**

```bash
npm run test:e2e
```

Скрипт в `package.json` перечисляет флоу явно: `01 → 02 → 03 → 04 → 05`.

**Весь каталог (порядок не гарантирован):**

```bash
maestro test e2e
```

Maestro перечисляет файлы в порядке файловой системы — порядок может отличаться
от нумерации. Поэтому каждый флоу обязан быть самодостаточным (см. ниже);
npm-скрипт существует как основной способ и страховка.

Требования: устройство/emulator с dev-клиентом, bundle id `com.llamerr.cattracker`.

## Идемпотентность и зависимости

- Каждый флоу сам навигирует на нужную вкладку (тапает «Дневник»/«Статистика») —
  поэтому дублирующая самодостаточность сохранена и при запуске каталога напрямую.
- `01_first_cat` идемпотентен: если кот уже есть, создание пропускается. Единственная
  data-зависимость всей серии — он должен был выполниться хотя бы раз (кот в БД).
- `05_edit_event` самодостаточен: создаёт своё кормление через «Быструю запись» и
  редактирует его, не полагаясь на `02`.
- `clearState` не используется — он стирает сохранённый URL Metro у dev-клиента.

## Флоу

| Файл | Что проверяет |
|---|---|
| `01_first_cat.yaml` | Первое добавление кота в настройках |
| `02_add_feeding.yaml` | Запись кормления через «Быструю запись» |
| `03_stats.yaml` | Сводка за сегодня на вкладке статистики |
| `04_quick_blocks.yaml` | Настройка быстрых блоков: выключение скрывает кнопку, включение возвращает |
| `05_edit_event.yaml` | EventSheet: смена типа события и стула, сохранение в карточку |

## TestID для e2e

Кнопки/карточки, заведённые специально под селекторы: `add-cat-button`, `cat-name-input`,
`cat-save-button`, `quickadd-{food|pee|poop}`, `toggle-{id}`, `move-up-{id}`, `move-down-{id}`,
`event-card-{type}`, `event-type-{type}`, `stool-{quality}`, `event-sheet-save`.
